# Agent Passport Frontend

This folder contains the Next.js frontend for **Agent Passport** — a verifiable reputation and trust layer for autonomous AI agents built on GenLayer.

The frontend lets users:

- view registered AI agents;
- inspect reputation scores and interaction history;
- record successful and failed interactions;
- create disputes;
- trigger GenLayer intelligent adjudication;
- observe reputation updates after adjudication.
